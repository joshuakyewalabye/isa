ISA STUDY LAB — BUC3126

OPENING THE SITE
1. Extract the complete ISA_Study_Site folder from the ZIP.
2. Keep the assets folder beside the HTML pages.
3. Open index.html in a modern browser.

LIVE STUDY TOOLS
- Search the complete guide from the search field. Press / or Ctrl + K to focus it.
- Mark topics as studied and tick off individual sections as you work.
- Save section bookmarks; they appear in the sidebar.
- Open Page notes to write notes for the current topic. Notes autosave in this browser and can be exported as .txt.
- Use the 15, 25 or 45 minute focus clock for a study sprint.
- Use Focus view to reduce distractions while reading.
- Existing recall cards, quizzes, visual labs, revision tests and the course text remain included.

Progress, bookmarks, notes and timer settings are stored locally in the browser on this device.
They are not synced to an account or sent to a server. Keep the full folder together when moving the site.
